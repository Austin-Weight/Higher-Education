# Python_EDA_Project_using_"Predict_Students'_Dropout_and_Academic_Success"_and_"College_Scorecard"
In this exploratory data analysis using Python, I made an insight into the dropout and academic success and several in the college scorecard dataset. The first set is a collection of data on students and the latter on institutions of higher education in the USA, with an emphasis on Utah. I imported the necessary Python libraries; read the datasets; cleansed the data by filtering, dealt with missing values, etc.; created and concluded on analyses; and developed visualizations. The reader will find himself/herself with a palette of beautiful analyses from well cleansed and manipulated data.
